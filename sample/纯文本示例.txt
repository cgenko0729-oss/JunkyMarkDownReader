纯文本模式示例 (.txt)
====================

这一份是 .txt，所以下面这些 Markdown 符号都**不会**被解析：

# 这不是一级标题
## 这不是二级标题

* 这不是项目符号
- 这也不是

**这不会变粗体**   `这不会变行内代码`

[这不是链接](https://example.com)

缩排与空格原样保留：
    四个空格的缩排
	一个 Tab 的缩排
        八个空格

    key = value        # 对齐用的空格不会被吃掉
    name = 张三
    port = 8080
